# SQL Date and Time Functions Assignment

## Overview

This assignment focuses on SQL Date and Time Functions using an event management dataset. The goal was to analyze event schedules, durations, registration deadlines, revenue, and quarterly performance using various date and time operations.

## Database Details

- **Database:** `eventmgmt_db`
- **Table:** `events`

## Concepts Covered

### Current Date & Time Functions
- CURDATE()
- CURTIME()
- NOW()

### Date Extraction Functions
- YEAR()
- MONTH()
- DAY()
- HOUR()
- MINUTE()
- SECOND()

### Date Formatting Functions
- DATE_FORMAT()
- MONTHNAME()
- DAYNAME()

### Date Arithmetic Functions
- DATE_ADD()
- DATE_SUB()

### Date Difference Functions
- DATEDIFF()
- TIMESTAMPDIFF()

### Other Date Functions
- QUARTER()
- WEEK()
- LAST_DAY()
- STR_TO_DATE()
- DAYOFWEEK()


## Key Learning Outcomes

- Working with DATE, TIME, and DATETIME data types.
- Formatting dates for reporting purposes.
- Performing date arithmetic and comparisons.
- Generating monthly and quarterly summaries.
- Using date functions in filtering, grouping, and aggregation.
- Solving real-world scheduling and reporting problems using SQL.


## Conclusion

This assignment strengthened my understanding of SQL Date and Time Functions by applying them to real-world event management scenarios involving scheduling, duration tracking, deadline analysis, and performance reporting.
