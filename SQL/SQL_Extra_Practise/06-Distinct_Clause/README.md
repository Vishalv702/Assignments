# SQL DISTINCT Clause Assignment

## Overview
This assignment focuses on the SQL `DISTINCT` clause and its use in identifying unique values, combinations, and business insights from retail sales data.

## Concepts Covered
- DISTINCT
- COUNT(DISTINCT)
- DISTINCT with multiple columns
- DISTINCT with computed columns
- CASE with DISTINCT
- Aggregate functions
- Data classification and reporting


## Database
- **Database:** `retail_db`
- **Table:** `sales_data`

## Key Learnings
- Retrieved unique business dimensions such as regions, cities, products, and categories.
- Generated unique combinations for analytical reporting.
- Applied DISTINCT on calculated values such as revenue and discounted prices.
- Used COUNT(DISTINCT) for unique counts and coverage analysis.
- Combined DISTINCT with CASE expressions for business classifications.

## Outcome
Developed practical experience in using SQL DISTINCT for data cleaning, reporting, and business analytics scenarios commonly used in real-world applications.
